# Inkloom AI Brand Intelligence Hackathon --- Documentation

## Project concept

**Founder-to-Launch Brand Intelligence Agent**

A multi-stage AI product that takes a rough
startup/product/community/creator idea and turns it into a structured,
launch-ready brand system.

The product is designed around the problem statement in the Inkloom
Participant Handbook: the system should improve brand decisions rather
than simply return one large block of generic text.

## Core workflow

1.  Discover --- understand the idea, audience, problem, goals and
    constraints.
2.  Position --- define category, differentiator and value proposition.
3.  Shape --- develop personality, naming directions, voice, tagline and
    messaging.
4.  Visualize --- create a visual design brief covering typography,
    colors, imagery, symbols and mood.
5.  Challenge --- detect clichés, contradictions, weak assumptions and
    audience mismatch.
6.  Deliver --- generate a consistent brand kit and practical launch
    assets.

## Main output

The user receives:

-   Audience and idea analysis
-   Positioning and value proposition
-   Brand personality and principles
-   Naming directions with rationale
-   Tagline and one-line pitch
-   Visual design brief
-   Brand voice and sample messages
-   Consistency/quality checks
-   Launch-ready content
-   Shareable/exportable brand kit

## Important hackathon principle

This must be a **working product**, not only a presentation. The demo
must show a real user input, the AI workflow and a real generated
output.

The system should expose its staged workflow and preserve structured context between stages instead of using one giant prompt.
